Overview

The game

Shrodunnit is a narrative-driven interactive comic that explores the theory of Schrodinger's thought experiment. Through two different events, the player observes missing items from one event being present in the other, emphasizing the idea of observing and being observed in turn. The game was built in Unity with a focus on integrating Ink for branching dialogue and narrative choices.

My contribution

What I built

  • Writing the dialogue scripts and narrative content.
  • Implementing the Ink integration for branching dialogue.
  • Implementing a scrolling text feature for displaying narrative text.
  • Adding a feature to click to fast-forward through dialogue.
  • Implementing nameplates and portrait changes to reflect the currently speaking character.

Technical Challenge

NPC Memory

One feature I wanted to implement was a memory system for the NPCs, where they would remember the player's actions and choices throughout the game, which would affect dialogue later on. Time constraints and story direction caused this feature to be cut from the build, as we decided it would be better narratively to focus on the two events and the player's observation of them, rather than having the NPCs remember the player's actions.
