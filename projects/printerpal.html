Overview

The app

PrinterPal is an iOS application that uses image recognition to identify 3D printer models and provide a series of tutorials for operating them, based on which model the app was recognizing. The app was built in XCode using Swift and ARKit to provide an interactive experience for users to learn about 3D printing. The CoreML AI model was trained using a dataset of 3D printer images to accurately identify different models and provide relevant tutorials.

My contribution

What I built

  • Implementing the image recognition system using ARKit and CoreML.
  • Developing the user interface for displaying tutorials and information.
  • Integrating the AI model with the application to provide accurate model identification.

Technical Challenge

AR Implementation & Model Training

The main challenges of this project were implementing the ARKit buttons and interactions, as well as training the CoreML model to accurately identify different 3D printer models. The ARKit implementation required a deeper understanding of how the interactive elements worked and how to integrate them into the ViewController to provide a seamless experience for users. The CoreML model training required a significant amount of data collection and preprocessing to ensure that the model could accurately identify different 3D printer models.
